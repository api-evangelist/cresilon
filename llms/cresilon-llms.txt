# Cresilon

> Cresilon is a Brooklyn, New York biotechnology company that develops, manufactures and markets
> hemostatic medical devices built on a proprietary plant-based hydrogel that stops moderate to
> severe bleeding in seconds without manual pressure. Its products are VETIGEL (veterinary) and
> TRAUMAGEL (human trauma care, FDA 510(k) cleared 2024, US nationwide launch January 2025).
> Cresilon publishes NO developer program and NO product API. The only machine-readable interface
> it exposes is the WordPress REST content API behind cresilon.com, documented below.

## What this API is, and is not

The eight OpenAPI 3.1.0 specifications below describe the anonymously readable half of the
WordPress REST API at https://cresilon.com/wp-json/. They were derived by API Evangelist from the
live route index (45 namespaces, 1,021 routes) by probing each route without credentials and
documenting only those that returned HTTP 200. This is a corporate-website content API. It is
NOT a clinical, ordering, inventory, distribution or product API, and nothing in it should be
treated as medical guidance or as a regulated device interface.

- No authentication is required for any operation listed here.
- No rate limits, quotas, Retry-After or caching validators are published. Self-throttle.
- Write operations exist on the same routes but return HTTP 401 to anonymous callers and are
  deliberately not documented.
- The provider makes no stability, versioning, deprecation or availability commitment.

- [Cresilon Pages API](https://cresilon.com/wp-json/wp/v2/pages): 53 pages — Our Story, TRAUMAGEL,

- [Cresilon Media API](https://cresilon.com/wp-json/wp/v2/media): 1,307 attachments — product

- [Cresilon Taxonomy API](https://cresilon.com/wp-json/wp/v2/categories): 2 categories (News,
  Press Releases) and 4 tags (biotech, cresilon, fda clearance, vetigel).
- [Cresilon Search API](https://cresilon.com/wp-json/wp/v2/search): cross-content search over
  posts and pages returning id / title / url / type / subtype.
- [Cresilon Discovery API](https://cresilon.com/wp-json/): the self-describing route index, plus
  the type, taxonomy, status and author registries.
- [Cresilon oEmbed API](https://cresilon.com/wp-json/oembed/1.0/embed): oEmbed 1.0 rich metadata
  for any cresilon.com URL, JSON or XML.
- [Cresilon SEO Metadata API](https://cresilon.com/wp-json/yoast/v1/get_head): rendered Yoast SEO
  head and its schema.org JSON-LD graph for any cresilon.com URL.

## How to use it correctly

- Pagination is page-number, not cursor. Send `page` and `per_page` (1-100; 999 returns HTTP 400
  `rest_invalid_param`). Read `X-WP-Total`, `X-WP-TotalPages` and the RFC 8288 `Link` header.
- Always send `_fields` to trim the response. Post and page objects carry a large `yoast_head`
  string and a full `yoast_head_json` graph by default — one untrimmed page object measured 51 KB.
- Send `_embed=true` to inline author, featured media and terms instead of following the numeric
  id references separately.
- Errors are NOT RFC 9457 problem+json. They are `{code, message, data.status}` in
  application/json. Capability failures come back as 401, not 403, and no credential will fix
  them. One error code, `invalid_user_permission_view_admin` (Jetpack), breaks the `rest_*`
  prefix convention.
- Post IDs and page IDs share one numbering space. Requesting a page ID under `/wp/v2/posts/{id}`
  returns 404 `rest_post_invalid_id`. Use the Search API's `subtype` field to route correctly.
